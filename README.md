### Things I've built

**[Describe My Environment](https://github.com/sorryshady/stats-507-assignment)**
A dual-loop assistant for blind and low-vision users. A 30 FPS YOLO11n loop
handles collision warnings; an on-demand BLIP + Llama 3.2 loop narrates spatial
context in natural language. Shared Python core, FastAPI backend, Next.js frontend.

**[Syllabus Parser](https://github.com/sorryshady/syllabus-parser)**
Paste a messy syllabus, get back a validated schedule. Schema-validated structured
output with Zod: when the model response fails validation, the app retries once with
the validation errors fed back into the prompt. The bundled sample is deliberately
awful, because a clean syllabus is parseable with a regex.

**[Job Scraper](https://github.com/sorryshady/Job-Scraper)**
Daily pipeline pulling ML/AI listings from three sources, deduplicating against
Notion, inserting only net-new rows. Ran unattended on cron.

**[Price2Quote](https://github.com/sorryshady/price2quote)**
Full-stack quoting tool. Gemini-generated pricing recommendations, PDF export with
branding, Gmail OAuth for sending quotes directly.

**[AOEK](https://github.com/sorryshady/aoek-prod-v2)**
Production React Native app. Published to the App Store and Play Store,
distributed by invite.
